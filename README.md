# 🧮 Advanced Calculator

A stylish and feature-rich web-based calculator built with **HTML**, **CSS**, and **JavaScript**. This calculator supports standard, scientific, and memory operations, along with a dark/light theme toggle and history tracking.

## 🚀 Live Demo

[Click here to view the demo](https://dsdipto7.github.io/CodeAlpha_Calculator/) 

---

## ✨ Features

- 🧮 **Basic Arithmetic** — Addition, Subtraction, Multiplication, Division
- 🧠 **Memory Functions** — MC, MR, MS, M+ operations
- 🧪 **Scientific Functions** — `sin`, `cos`, `tan`, `log`, `sqrt`, `^` (power)
- 🌓 **Theme Toggle** — Switch between Light and Dark modes
- 📜 **Calculation History** — View previous calculations instantly
- 🖥️ **Responsive Design** — Works across all screen sizes
